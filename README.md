# 基于深度学习的ABL1/SRC/LCK激酶抑制剂选择性预测研究

> 覆盖ABL1/SRC/LCK三靶点，深度学习预测激酶抑制剂选择性档位。

## 数据一览

| 文件 | 行数 | 用途 |
|---|---|---|
| `data/p20_AblSrcSel_main.tsv` | 2500 | 主训练集 |
| `data/p20_AblSrcSel_ext1.tsv` | 692 | 外部验证集 1 |
| `data/p20_AblSrcSel_ext2.tsv` | 531 | 外部验证集 2 |

数据来源：ChEMBL 公开活性数据库（pchembl 中位数切分 HIGH/MOD）
涉及靶点：ABL1, LCK, SRC

## 技术路线（摘要）

化合物 **Morgan 分子指纹 (2048 维)** ⊕ 靶点 **ESM2-150M 蛋白语言模型嵌入 (640 维)**
→ **GPU 多层感知机**（动态扩缩批训练）→ 活性档位预测（HIGH/MOD 或多分类）。

- 内部验证：主训练集 80/20 分层切分
- 外部验证：ext1 / ext2 两个独立通道全量推理
