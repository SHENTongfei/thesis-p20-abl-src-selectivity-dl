# 基于深度学习的 ABL1 转化相关激酶先导物智能判别与寻优

> 以 ABL1 在慢性髓性白血病中的经典靶点为依托，用深度学习判别并寻优先导化合物，延续酪氨酸激酶抑制剂研发范式。

## 一、方法

- **模型**：Transformer 编码器 + CLS 聚合（SMILES 预训练式）

- **输入**：SMILES 字符级 token 序列
- **训练规模**：2500 条样本，2 类
- **标签协议**：rel
- **验证**：5 折分层交叉验证 × 3 随机种子 = 15 次独立训练
